# Ландшафтная карта из DXF

Веб-дашборд для ландшафтного проектирования: загружает DXF-чертёж участка,
разбирает слои, классифицирует ландшафтные зоны, строит интерактивную карту
и формирует печатный план PDF (A3).

**Онлайн-версия:** <https://genocide12.github.io/landscape-dxf-dashboard/>

## Возможности

- **DXF-конвейер** — парсинг ASCII DXF: LINE, LWPOLYLINE, POLYLINE, CIRCLE, ARC,
  TEXT, MTEXT, SPLINE, POINT, INSERT (встраивание блоков с масштабом и поворотом),
  таблица слоёв, единицы чертежа ($INSUNITS с автоопределением мм/м).
- **Классификация зон** — слои с русскими и английскими названиями («Газон»,
  «Вода», «Дорожки», «Дом», «Деревья»…) распознаются в 10 ландшафтных категорий.
- **Интерактивная карта** — CAD-минимализм: сетка с подписями, зум колесом,
  панорама, перекрестие, координаты курсора, инспектор объектов (длина, площадь,
  радиус), включение/отключение зон.
- **Экспорт PDF (A3)** — векторный план в масштабе 1:50–1:2000, CAD-сетка,
  легенда с площадями, штамп с датой и масштабом, габаритные размеры.
- **AI-консультант** — живой чат с ландшафтным дизайнером, который видит
  контекст загруженного участка (зоны, площади, долю озеленения).
- **Демо-участок** — встроенный пример 20×30 м для мгновенного знакомства.

## Технологии

Next.js 16 (App Router) · TypeScript 5 · Tailwind CSS 4 · shadcn/ui ·
jsPDF (векторный экспорт) · z-ai-web-dev-sdk (AI-чат, серверная часть)

## Запуск локально

```bash
bun install
bun run dev        # http://localhost:3000
```

Экспорт плана и DXF-конвейер полностью работают в браузере. AI-консультант
требует серверную часть (`/api/chat`), поэтому на статической странице
GitHub Pages он сообщает об отсутствии бэкенда — это ожидаемое поведение.

## Структура

```
src/
  lib/
    dxf/parser.ts      # парсер DXF (объекты, слои, блоки, единицы)
    dxf/classify.ts    # классификация слоёв → ландшафтные зоны
    dxf/demo.ts        # генератор демо-участка 20×30 м
    geometry.ts        # площади (shoelace), длины, bbox, сводка
    pdf-export.ts      # векторный PDF A3 (сетка, легенда, штамп)
  components/
    MapCanvas.tsx      # интерактивная SVG-карта
    ChatPanel.tsx      # панель AI-консультанта
  app/
    page.tsx           # дашборд (вкладки: Участок / AI-консультант)
    api/chat/route.ts  # серверный роут AI-чата
public/fonts/          # DejaVuSans.ttf — кириллица в PDF
scripts/               # сборка GitHub Pages, деплой, тесты конвейера
docs/                  # сценарий видеоурока и материалы
```

## Поддержка DXF

- Формат: ASCII DXF (бинарные DXF отклоняются с понятной ошибкой)
- Кодировки: UTF-8 и Windows-1251 (автоопределение)
- Размер файла: до 15 МБ
- Дуги аппроксимируются отрезками, bulge-сегменты полилиний упрощаются
